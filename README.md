# Tugas Distribusi Kontinu
Repository ini berisi pengerjaan tugas Distribusi Kontinu menggunakan R.

## Materi 
Tugas ini menggunakan beberapa distribusi kontinu, yaitu:
1. Distribusi Eksponensial
2. Distribusi Uniform
3. Distribusi Normal

## Soal yang Dikerjakan
1. Peluang waktu tunggu dengan distribusi Eksponensial.
2. Varians waktu tunggu kereta dengan distribusi Uniform.
3. Peluang masa pakai sensor sebelum mengalami kerusakan dengan distribusi Eksponensial.
4. Proporsi kemasan kopi yang tergolong *underweight* dengan distribusi Normal.

## Tools
* R
* RStudio
